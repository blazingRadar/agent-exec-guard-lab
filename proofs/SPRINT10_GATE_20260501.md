# Sprint 10 Gate: Observe -> Generate -> Review -> Enforce Policy Workflow

Date: 2026-05-01

Status: PRE-REGISTERED BEFORE IMPLEMENTATION

## Goal

Sprint 10 turns the Sprint 9 guided demo into a more usable product workflow.

Target claim:

> A reviewer can take real guard audit logs from a successful OpenHands run, generate a reviewable YAML policy from the observed executable identities, compile that YAML into the guard's JSON policy format, and rerun the guarded OpenHands demo using the generated policy.

This is not a new kernel/security-mechanism sprint. The guard source and binary should remain unchanged unless a blocking bug is found and disclosed.

## Prior State

Sprint 9 proved:

- editable hand-authored YAML policy compiles to guard JSON;
- one-command guided demo runs on the prepared lab machine;
- OpenAI `gpt-5.2` drives OpenHands `execute_bash`;
- guard allows expected executable identities;
- guard blocks copied `/usr/bin/rm` renamed to `./python3`;
- denial is asserted from current-run OpenHands trajectory;
- post-audit cleanup added dynamic repo root, preflight checks, aggregate pass/fail summary, and container cleanup.

Sprint 9 did not prove:

- public self-serve clone-and-run packaging;
- automatic policy generation from observed runs;
- production sandbox security;
- full OpenHands web UI;
- non-`CmdRunAction` coverage;
- F4 closure.

## Acceptance Criteria

Sprint 10 passes only if all are true:

1. Gate commit precedes implementation/proof commit in git history.
2. Guard source and binary remain unchanged, unless a blocking bug is found and disclosed.
3. A policy generator exists that reads guard audit JSON records and emits reviewable YAML.
4. The generator includes observed `ALLOW` executable identities and reports observed `BLOCK` records separately.
5. The generated YAML is accepted by `scripts/policy/compile_policy.py`.
6. A workflow script exists that runs observe/generate/compile/enforce on the prepared lab machine.
7. The enforce rerun using the generated policy passes the guarded OpenHands demo at least once, or preserves a bounded frontier-model variance failure.
8. The workflow preserves run artifacts under `proofs/sprint10_runs/`.
9. The workflow records aggregate `pass=N fail=N`.
10. Documentation names exact claims and non-claims.

## Stop Conditions

Stop and report a bounded blocker if:

- OpenHands frontier-model variance prevents the enforce rerun from executing the target command after two preserved attempts;
- the generated policy omits required startup executables seen in observed guard logs;
- generated YAML cannot compile without weakening validation;
- the workflow requires changing the guard architecture.
