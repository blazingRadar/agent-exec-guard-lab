# Proof Archive

This directory is the audit trail, not the primary developer entry point.

- `audits/`: independent reviews and follow-up reviews
- `gates/`: pre-registered sprint gates
- `memos/`: proof memos, self-audits, and cleanup notes
- `command_logs/`: preserved command logs
- `index/`: current audit index
- `sprint*_runs/`: preserved replay artifacts

The runnable project surface is in `src/`, `scripts/`, `policy/`, `docs/`, and the root `Makefile`.
